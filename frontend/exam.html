Exam Scheduling Guide

×

Follow these steps to generate and manage examination schedules.

  1. Filter Academic Year & Semester Select the Academic Year and Semester to filter and display the saved class schedules and sections available for exam generation.
  2. Set Exam Dates & Exam Type Add one or more examination dates using the date picker (e.g. Day 1, Day 2, Day 3) and select the Exam Type (Preliminary, Midterm, or Final).
  3. Select Sections Check the boxes for the specific class sections you want to schedule, or check the header box to select all sections at once.
  4. Generate Exam Schedule Click Generate Exam Schedule. The system automatically assigns exam dates, time slots, and rooms while avoiding section time conflicts and room double-bookings.
  5. Review & Save Review the generated timetable in the preview modal, then click Save Exam Schedule. Saved exams sync to Firestore and appear in the Saved Exam Schedules section.
  6. Export & Manage Use Export All to PDF to generate printable examination timetables, or manage existing schedules using individual and bulk delete options.

Tip: You can reopen this guide anytime by clicking the ⓘ button at the top-right of this page.
